Typography

Use <hgroup> only for a compact heading and subtitle: a direct real heading plus supporting paragraph. It preserves the heading level, adds a 4px internal gap and muted subtitle, and keeps normal document spacing. Cards and dialogs use 18px titles and 14px subtitles; slides keep responsive slide typography.

Solid accent composition

The documented .accent surface uses --accent and --accent-foreground. It composes with button sizes, icons, full width, groups, navigation links, dropdown summaries, and disabled/busy states. Keep it mutually exclusive with other surface variants; bare buttons remain primary.

Sidebar

<aside class="sidebar"> is a direct child of <body> with an optional direct header, required nav, and optional direct footer. Header and footer have full-width separators and remain visible while only the nav scrolls. A nav-only sidebar is also supported. By default, it is a persistent desktop rail and a native mobile drawer; the .sidebar-toggle is shown only on mobile. Add .drawer to make it a native hidden drawer at every width: use the same .sidebar-toggle, the layout does not shift, and no JavaScript is needed. A visible-by-default, stateful desktop collapse is not provided because it requires application state and JavaScript.

Navigation

Responsive Top Navigation

Ordinary navs keep wrapping by default. For a sticky top bar, opt into one .top-nav-menu[popover] link list: it stays horizontal on desktop and opens beneath the bar below 768px. The page header above is the live example.

Native popover behavior supplies light dismiss and Escape without JavaScript. Set --top-nav-height if the sticky bar is taller than Daft's default single row.

If an open mobile menu is resized to desktop, CSS aligns it with the desktop bar, but it remains in the browser's top layer until dismissed.

<nav class="top-nav sticky glass" aria-label="Primary">
  <ul><li><strong>Workspace</strong></li></ul>
  <button class="top-nav-toggle ghost icon"
          popovertarget="primary-menu"
          aria-label="Toggle primary navigation">
    <svg xmlns="http://www.w3.org/2000/svg" width="24" height="24"
         viewBox="0 0 24 24" fill="none" stroke="currentColor"
         stroke-width="2" stroke-linecap="round" stroke-linejoin="round"
         aria-hidden="true">
      <path d="M4 5h16"/>
      <path d="M4 12h16"/>
      <path d="M4 19h16"/>
    </svg>
  </button>
  <ul id="primary-menu" class="top-nav-menu" popover>
    <li><a href="/projects">Projects</a></li>
    <li><a href="/team">Team</a></li>
  </ul>
</nav>
