Daft Slides.

Semantic HTML for presentation decks.

Each slide demonstrates one capability of the slide layer.

A deck is a stylesheet away.

Add class="deck" to <body>. Every <section> becomes a slide. No runtime, no build, no framework.

The whole API.

<body class="deck">
  <section class="title">
    <hgroup>
      <h1>Q4 review</h1>
      <p>What shipped, what's next</p>
    </hgroup>
  </section>
  <section>
    <h2>Highlights</h2>
    <ul><li>…</li></ul>
  </section>
</body>

Not just 16:9.

Set the proportions you need.

Override --slide-width and --slide-height on the root. Screen layout and PDF page both follow.

:root {
  --slide-width: 4;
  --slide-height: 3;    /* classic 4:3 */
}

:root {
  --slide-width: 9;
  --slide-height: 16;   /* portrait */
}

Width × Height

  • 16 / 9 — Default widescreen
  • 4 / 3 — Classic
  • 1 / 1 — Square (social)
  • 9 / 16 — Portrait (phone)

Unitless on screen; same numbers map to inches on print.
