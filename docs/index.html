What we kept from others

We picked the parts we liked.

Three honest comparisons against the libraries Daft borrowed from. Same goals, different trade-offs.

vs Pico.css

Same idea, a sharper finish.

Pico opened the door: style plain HTML without classes. Daft keeps that idea and pushes the visual finish toward shadcn-grade defaults — same markup, sharper outcome.

Pico.css 83 KB
Daft 59 KB
Aurora pipelines

Streaming ingest pipeline with backpressure handling.

vs daisyUI

Smaller than the plugin you'd add to Tailwind.

daisyUI's pitch is the one we like: readable semantic class names instead of utility soup. The trade-off is the dependency. daisyUI is a Tailwind plugin — you ship Tailwind, the JIT compiler runs, and daisyUI's output stacks on top. Daft is the single file you link.

Daft 59 KB
Pico.css 83 KB
daisyUI 158 KB
daisyUI + Tailwind 200 KB

Minified CSS, full default ruleset (not gzipped). daisyUI is a Tailwind plugin, so the real bundle adds Tailwind's compiled output on top.

vs Tailwind

One render, two ways to write it.

We borrow Tailwind's discipline around design tokens, modern color, and responsive primitives. Where Daft differs is what ends up in your markup. Same button, both styles below.

Daft

<button>
  Save changes
</button>

Tailwind

<button class="inline-flex
  items-center justify-center
  rounded-md text-sm font-medium
  transition-colors
  disabled:opacity-50
  bg-primary
  text-primary-foreground
  hover:bg-primary/90
  h-10 px-4 py-2">
  Save changes
</button>
