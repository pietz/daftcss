Daft Slides

Semantic HTML for presentation decks.

The problem

Agents write HTML well, but every deck reinvents the same six layouts.

  • Markdown is too rigid
  • Raw HTML reinvents the wheel
  • Slidev and Reveal both ship a runtime

Split layout

Heading at the top spans both columns automatically.

Use this for feature + screenshot, claim + evidence, or before + after.

Asymmetric split (2:1)

Use cols-3 with a span-2 child for a 2:1 ratio. No new vocabulary — just Daft's grid primitives.

Three things

Semantic

<section> is a slide. No divs required.

Themable

Inherit Daft tokens. Override five vars.

PDF-ready

Browser print. No tooling required.

Give the agent a vocabulary, not a runtime.
— A reasonable take
Speaker notes are hidden by default. Reserved markup for a future presenter mode.

Just write HTML

<body class="deck">
  <section class="grid cols-2">
    <h2>Heading</h2>
    <div><p>Left</p></div>
    <figure><img src="..."></figure>
  </section>
</body>
