Event API

Create a subscription

Register an HTTPS endpoint to receive a filtered, signed stream of events from your RelayGrid workspace.

POST /v1/subscriptions API 2026-04
Versioned for predictable integrations

Send RelayGrid-Version: 2026-04 with every request. Existing versions remain available for 18 months after deprecation.

Before you begin

Create a restricted service token with the subscriptions:write scope. Tokens are workspace-specific and should only be sent over HTTPS.

Authorization header HTTP 
Authorization: Bearer rg_live_••••••••••••
RelayGrid-Version: 2026-04
Content-Type: application/json
Keep live tokens in your server-side secret store, never in browser code.

Send the request

The endpoint must acknowledge deliveries with any 2xx response within five seconds. RelayGrid signs every request and retries transient failures with exponential backoff.

Create an order event subscription cURL 
curl https://api.relaygrid.dev/v1/subscriptions \
  --request POST \
  --header "Authorization: Bearer $RELAYGRID_TOKEN" \
  --header "RelayGrid-Version: 2026-04" \
  --header "Content-Type: application/json" \
  --data '{
    "endpoint": "https://hooks.acme.test/relaygrid",
    "events": ["order.created", "order.fulfilled"],
    "description": "Production order pipeline"
  }'
Base URL: https://api.relaygrid.dev

Request parameters

Pass a JSON object in the request body. Unknown properties are rejected so configuration mistakes surface early.

Property Type Required Description
endpoint string · URI Required Public HTTPS URL that receives event deliveries.
events string[] Required One to 25 event types. Wildcards are not accepted.
description string Optional Human-readable label, up to 120 characters.
metadata object Optional Up to 10 key-value pairs returned with the resource.
JSON body accepted by POST /v1/subscriptions.

Response

A successful request returns 201 Created with the subscription in pending state. RelayGrid sends a verification event before activating delivery.

201 Created JSON 
{
  "id": "sub_01JY7Q9ATDJ5K8N4FV3M2R6XBC",
  "object": "subscription",
  "status": "pending",
  "endpoint": "https://hooks.acme.test/relaygrid",
  "events": ["order.created", "order.fulfilled"],
  "created_at": "2026-04-18T14:32:08Z"
}

Response fields

id
Stable, sortable subscription identifier.
status
One of pending, active, paused, or disabled.
created_at
Creation time in ISO 8601 UTC format.

Errors and retries

Errors use a consistent envelope with a stable code, a human-readable message, and a request ID for support.

Never retry authentication failures automatically

A 401 indicates an absent, expired, or revoked token. Rotate the credential before trying again.

400 · Invalid request

The JSON is malformed, includes an unknown property, or fails field validation. Inspect error.fields before sending a corrected request.

409 · Endpoint already registered

An active subscription already uses the same endpoint and event set. Reuse or update the existing subscription.

429 · Rate limit exceeded

Wait for the number of seconds in Retry-After. Create requests are limited to 60 per minute per workspace.

Verify delivery signatures

Compute an HMAC-SHA256 digest over the exact request body and compare it with RelayGrid-Signature using a constant-time operation. Reject timestamps older than five minutes.

Read the raw body before parsing JSON. Re-serializing the payload changes its bytes and invalidates the signature.
