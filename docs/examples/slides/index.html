Daft Slides

Semantic HTML for presentation decks.

The problem

Every team reinvents the same six layouts.

  • Markdown is too rigid
  • Raw HTML reinvents the wheel
  • Slidev and Reveal both ship a runtime

Two-column grid

Heading sits above the grid as a sibling.

Use this for feature + screenshot, claim + evidence, or before + after.

Weighted grid (2:1)

Put span-2 on one child of a two-child .grid to get a 2:1 ratio. No new vocabulary — just Daft's grid primitives.

Three things

Semantic

<section> is a slide. No divs required.

Themable

Inherit Daft tokens. Override five vars.

PDF-ready

Press Cmd + P and save as PDF. No tooling required.

Give the agent a vocabulary, not a runtime.
— A reasonable take
Speaker notes are hidden by default. Reserved markup for a future presenter mode.
