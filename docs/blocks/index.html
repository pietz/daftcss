FAQ Accordion

FAQ

Questions before you start?

Does this require JavaScript?

No. Daft components use native HTML whenever possible.

Can I change the visual style?

Yes. Change root CSS variables for spacing, radius, color, and type scale.

Should I add custom classes?

Use utilities and semantic elements first. Add custom CSS only for product-specific needs.
